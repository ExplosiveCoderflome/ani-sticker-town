# 小镇贴纸簿 v0.9 · AI 动作贴纸工坊

刚下船的游客想在摊边吃口热的，躲雨的读者想坐着看完最后一章。拆开街坊的来信，亲手摆动贴纸，看看一张挪了位置的椅子会把谁留下。街上也有可以自由布置的地方，想做新主题时可以去 AI 工坊画自己的贴纸。

**2026-11-24 · AI 动作贴纸工坊**　输入自己的主题后，可以同时生成四件互动贴纸和角色的走近、接取、使用、带物离开四组动作。也可以导入自己的 4×4 动作图集。动作会绑定到同盒的摊位、桌子和凳子，摆近后角色会使用对应物件。内置《海边的水彩画室》可直接试玩。[去动作工坊](http://127.0.0.1:8765/?workshop=1) · [下载 v0.9](releases/sticker-town-v0.9.zip) · [更新记录](docs/releases/release-notes.md)

## 选一种玩法

| 你想做什么 | 怎么开始 |
| --- | --- |
| 第一次来玩 | 解压后启动游戏，点「拆开第一封信」。先试着把已选中的游客放在烤鱿鱼摊旁。完成心愿后点「收下」，从回信接下一封。离开时，已完成的心愿和各封信的布景会分别保留。 |
| 接着上次玩 | 用同一浏览器和本机端口打开封面，点「继续」或选择已解锁的来信。[街角来信](http://127.0.0.1:8765/?story=1) |
| 直接逛灯火夜市 | 打开[夜市样盒](http://127.0.0.1:8765/?market=sample)。四张透明贴纸由 ImageGen 预先绘制，游戏包内已带齐，断网也能用本机服务开市。 |
| 打开主题工坊 | 选择「海边的水彩画室」、海风夜市或雨天书屋。画师、游客和读者会使用各自绑定的动作。[本机工坊](http://127.0.0.1:8765/?workshop=1) |
| 用自己的主题画一盒 | 在工坊输入一句话，例如「山顶的陶艺工作室」，勾选角色动作后点「生成整盒与 4 组动作」。也可以选「复制绘图单」，交给常用的 AI 绘图工具，分别导入四件贴纸图和一张 4×4 动作图集。 |
| 自由造景，和角色玩一会儿 | 打开[我的街角](http://127.0.0.1:8765/?garden=1)。贴近的角色与物件可能发生一段小插曲。「街角手记」里记着你遇见过的事，还能听一条线索。 |
| 先当一次收件人 | 下载 [黑猫寄来的周末.html](releases/黑猫寄来的周末.html)，用浏览器打开。选一张贴纸，再点暖棕色轮廓，也可以直接拖过去。全部贴完即可查看寄件人的原作。文件内含底板、贴纸和玩法，断网也能玩。 |
| 下载完整游戏 | 解压[完整试玩包](releases/sticker-town-v0.9.zip)。Windows x64 双击 `开始试玩.cmd` 即可进入。macOS 和 Linux 在解压目录运行 `python3 tools/serve.py --open`，需要 Python 3.9 或以上和支持 WebGL 2 的浏览器。 |

启动后，可用支持 WebGL 2 的浏览器打开完整游戏，也可直接拆开示例来信。[本机试玩](http://127.0.0.1:8765/) · [黑猫寄来的周末](http://127.0.0.1:8765/weekend-letter.html)

如果默认端口被占用，启动器会选择附近的可用端口。也可以在解压后的目录运行下面的命令来启动游戏。

```sh
python tools/serve.py --open
```

## 拼一盒，或做一盒

- **开张和落座。** 客人会挑附近距离最近的摊位，走到摊前，付款取餐。在海风鱿鱼摊，条纹衫游客能坐在单独一张空凳上吃串。有人占着凳子，她会另找位置。其他主题可以把椅子配在桌边。轻点客人可以再招呼一次，「再逛一轮」让附近客人依次出发。本轮成交数在实际交接时增加。
- **摆自己的夜市。** 四件素材可以重复放置，同类物件按角色和位置互动。想亲手从第一张摆起，点「收起全部」，再从贴纸盘逐件拿取；误收可以点「撤销」。每套夜市单独保存布局。已绘好的夜市贴纸也能从「我的贴纸」带到普通街角，与其他集市的摊位和食客搭配。

- **拼官方盒。** 《周末小镇》和《广场午后》各有 14 件。查看“成品参考”，从贴纸盘拖动一件到对应位置，或先选贴纸再点画布。可以放大、撤销。用同一浏览器和本机地址回来，两盒分别恢复进度。
- **布置自己的街角。** “造景”有两份独立草稿。首次进入《周末小镇》有七件可以挪动的摆设，《广场午后》留白。旧草稿会直接恢复。每种贴纸可以重复使用，一盒容纳 1–15 件。可以移动、移除或撤销。演出结束时，角色会回到你选的位置。
- **寄给朋友。** 选“封装成礼物”，给它起名，再选“下载可玩的礼物”。把下载的 HTML 文件发给朋友，对方在自己的浏览器里从空板重拼。你用到的个性路牌和定制贴纸也随文件一起带走。接收方只需浏览器。在通信软件内打不开 HTML 时，可以先保存文件再用浏览器打开。
- **留一张成品。** “存明信片”会导出 PNG，保留作品中贴纸的摆放和遮挡。礼物链接适用于收件人也能访问的同一个游戏站点。当前本机地址只供这台设备使用。

## 做一块路牌，或请 AI 画贴纸

完整游戏中的贴纸工坊可以直接做文字路牌。成品保存在本机素材库，同一张可用于多个作品。默认素材库位于 Windows 的 `%LOCALAPPDATA%\StickerTown`，也可用 `TOWN_STICKER_DATA` 指定目录。浏览器中的关卡进度、草稿会随站点数据一起清除。

互动盒有四个位置：地点、桌子、座椅和角色。书屋会生成书摊、阅览桌、阅读椅和读者，夜市会生成摊位、摊桌、餐椅和食客。自定义主题还会保存角色动作与同盒目标物件的绑定。游戏根据贴纸的位置和所属类别安排互动，两种结局会记录在这一盒的画布下方。再次开盒可从「我的收藏」找回自己的作品。

导入四格图时，左上放地点、右上放桌子、左下放座椅、右下放角色，每件四周留出透明边缘。导入动作图时使用 4×4 网格，四行依次放走近、接取、坐下使用和带物离开，每行四帧。工坊会检查透明边缘、人物大小和动作差异，再让你确认预览。样盒与导入功能都能离线使用。已接通绘图服务时，也可以按主题生成四件贴纸和四组动作。

使用在线生成时，需要给服务进程设置 `RECRAFT_API_TOKEN`。Windows x64 试玩包已带 Pillow，自备 Python 环境请安装 Pillow。贴纸生成沿用逐件缓存，角色动作会参考角色原图逐组生成，并按动作组缓存，绘制中断后可以继续。Recraft 的图生图接口支持通过 `strength` 保留角色身份。[Recraft 图生图接口](https://www.recraft.ai/docs/api-reference/tools/image-to-image)

## 开发与重建

游戏源工程位于 `game/`，使用 Godot 4.7.2 Standard、GDScript 和单线程 Web 导出。安装同版本 Web 导出模板后，在源码工作区运行下面的命令即可重新构建试玩版。

```sh
python tools/build_web.py --godot "你的 Godot 可执行文件路径"
```

如果单独保存了 `web_nothreads_release.zip`，可通过 `--template` 指定文件。构建输出位于 `play/`，正式入口为 `index.html`。玩法、发布边界和验收项目见[首期方案](design/phase-1.md)。[Godot 引擎许可](https://godotengine.org/license/)
