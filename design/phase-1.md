# 《小镇贴纸簿》首期开发与验收

2026-11-21 · v0.4 中文浏览器版

制作者用不同贴纸布置一处小镇，再把它交给朋友。收件人从空板开始，把同一套贴纸拼回原来的景象。制作者可以给街景加上专属路牌，也可以给 AI 一个主题，为场景生成新的小屋、家具和居民。[技术选型](tech-stack.md)

## 已实现的玩法

| 环节 | v0.4 的实际行为 |
| --- | --- |
| 夜市互动 | 主题分成摊位、桌、椅、食客四张透明图。编辑时按实例间距离选摊和座位。走到摊前才成交，有座位就落座，无座则外带。预制样盒与新绘素材使用同一套互动。 |
| 街角互动 | 首次自由造景从一个可编辑的小镇街角开局。角色和物件靠近会触发四组独立演出。手记记录玩家亲眼发现的片段，同场仍有相应贴纸时可以再次观看。 |
| 拼官方盒 | 《周末小镇》和《广场午后》用同一套 14 件手绘贴纸构成两种布局。玩家可点选或拖动贴纸，查看参考图、缩放、撤销。两盒分别保存进度。 |
| 自由布置 | 选择底板，从 14 件街景物件和黑猫中挑选素材。允许同款多次出现，最多 15 个独立实例。可移动、移除、撤销。两个底板分别保存草稿。 |
| 个性路牌 | 工坊把玩家输入的文字画成一张独立 PNG。路牌进本机素材库后可以摆放、重用、装入礼物和明信片。 |
| AI 素材 | 配置 Recraft 令牌和 Pillow 后，可以单独委托一件物件，或按主题分别制作开放小屋、配套家具和居民。每件各自出图并去背景，得到独立透明 PNG。相同主题与角色的成功结果在本机复用。 |
| 封装礼物 | 作品包含标题、底板、各实例的素材标识、位置和前后顺序。完整游戏按礼物版本及布局隔离拼图进度。发送离线 HTML 时，随文件嵌入底板和各件原图，收件人断网也能重拼含个性路牌的作品。 |
| 收藏成品 | 玩家可导出 PNG 明信片。图片按作品中的坐标和层级合成，去除编辑角标和操作控件。 |

原始 PNG 和尺寸记录见[素材清单](../weekend-town/stickers.json)。当前两盒使用的 864 × 900 画布及槽位数据见[运行时布局](../game/assets/levels.json)。分享文件带有轻量浏览器拼图界面。完整创作工具运行在本机 Python 服务上，游戏画布使用 Godot Web 导出。[试玩与下载](../README.md)

## 一次完整体验

1. 打开首页，把小黑猫放到长椅旁，看它自己跳上椅子。把角色挪远再挪近，或点同一组角色，看街角作何反应。切换草稿和刷新后观察手记、贴纸位置和先前的发现记录。
2. 顶部切到“拼图”可打开两盒官方街景。从“造景”返回原作品，还可以做一块写给朋友的路牌，给街景起名。
3. 封装后导出可玩的 HTML，把文件发到另一台设备。在断网状态打开，依次贴回小猫、长椅和路牌，拼完可以查看原作。PNG 则用于直接展示成品。
4. 配有绘图令牌时，给工坊一个具体主题，例如“下雨天的旧书店”。依次检查空小屋、书架一类的单件家具与一名居民是否各自可拿取。再调整三者的位置，封成新的拼图。主题委托交付组件。自动生成整盒布局仍是后续阶段。

## 技术与交付边界

- **运行方式。** 完整包提供编译好的 Godot 4.7.2 网页版、本机启动器和 Python 素材服务。使用 Python 3.9+。离线礼物只依赖浏览器。试玩服务监听本机回环地址。若将来部署到公共地址，需要安排公共素材存储、服务授权及费用限制。
- **资源与进度。** 浏览器在本站点保存草稿、官方盒和礼物关卡的进度。本机 SQLite 保存自制路牌、生成图和已完成的主题件。完整游戏的链接通过当前站点读取定制件。离线附件直接携带所需图片。
- **生成成本。** 本机未配置令牌时，官方盒、创作、路牌与离线分享均可体验。启用在线工坊后，每个新件有生图和去背景两个计费步骤，同主题三件全部首次成功需六次调用。对补做、等待时间和成功件成本单独留量。真实画风一致性和首次合格率需要付费样本验证。

## 验收与下一轮验证

| 项目 | 验收方法 |
| --- | --- |
| 关卡和存档 | 两盒各拼满 14 件，刷新后恢复。验证贴错、撤销、同图多实例、同素材不同礼物的存档互不覆盖。 |
| 创作与图片 | 添加、挪动、删除、撤销。刷新后找回布局。对照明信片查看大小、透明边缘和图层，检查路牌中文字是否清楚。 |
| 离线交付 | 导出含自制路牌的礼物，阻断网络，用新浏览器打开，检查所有贴纸齐全且可完成。实测手机版文件接收、保存和打开步骤。 |
| 在线工坊 | 检查未配置时的可用性提示。用服务替身验证三种主题件的独立请求、部分失败后的复用和重试。另以小额真实调用测等待时间、抠图质量和单位成本。 |
| 真机与邀请 | iOS Safari 和 Android Chrome 分别检查首屏、窄屏贴纸盘、双指缩放、切后台及存档恢复。拿到可公开访问的部署后，再验证跨设备链接与收件人体验。 |

后续投入重点是看玩家能否独立拼完、是否愿意再布置一盒、朋友收到礼物后能否打开并落下第一张贴纸。若开始商业试验，再用实际到账、退款、生图、抠图和其他可变成本衡量每盒贡献，并在有完整观察窗口后统计七日复玩。
