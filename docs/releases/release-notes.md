# 贴纸小镇更新记录

### 2026-11-21

**新增**

- v0.9「AI 动作贴纸工坊」允许输入自定义主题，同时生成四件可单独摆放的贴纸和角色的四组动作。角色动作按角色、摊位、桌子和凳子绑定，摆到对应物件旁会走近、接取、坐下使用或带物离开。支持导入 4×4 透明动作图集，动作生成中断后可继续，内置《海边的水彩画室》可直接试玩。
- v0.8「雨天书屋」加入红贝雷帽读者的行走、借书、坐着翻页和抱书行走动作。把阅读椅移出桌边，她会带书离开。书屋和海风夜市都可直接从封面进入试玩。
- v0.7「海风夜市」为条纹衫游客加入走路、接串、持串行走和坐着吃串四组动作。在鱿鱼摊旁摆一张空凳，她会坐下吃。收走凳子，她就拿着烤串离开。空凳也能单独使用，有其他游客占着的凳子会被跳过。
- v0.6「街角来信」加入可连续完成的三封居民委托。帮游客入座、给读者安排阅读角，最后在同一条街上同时照顾两位居民。完成后亲手收下回信，才会解锁下一封。
- 三封信各自保存布景和心愿进度。收齐三张纪念票后，可以下载纪念明信片，并把奖励「街角蓝邮筒」带到自由造景里使用。
- Windows x64 下载包现在内置运行环境。解压后双击「开始试玩」即可离线游玩第一章。
- v0.5「主题工坊」加入两套 AI 绘制的四件贴纸。《海风夜市》的游客会买烤鱿鱼，《雨天的街角书屋》的读者会借书。挪动桌椅能改变角色的下一步，两种结局分别记录。
- 可以输入自选主题，通过 Recraft 逐件生成，或者复制绘图单后导入其他 AI 绘制的透明四格 PNG。玩家可以检查分件预览、单独摆放贴纸，并从收藏重新打开主题盒。
- v0.4「灯火夜市」提供四张可单独摆放的透明贴纸。客人会走到附近的摊位买餐，有桌椅时落座，挪远凳子就改为外带。
- 可以直接玩内置夜市。接入绘图服务后，也可以按自己的主题分别生成摊位、桌、椅和客人，和其他夜市的贴纸混搭。
- 下载包还收录了两盒街景拼图、自由造景、街角手记和离线拼图礼物。
