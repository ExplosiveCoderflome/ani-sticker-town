# 贴纸小镇更新记录

### 2026-11-21

**新增**

- v0.5「主题工坊」加入两套 AI 绘制的四件贴纸。《海风夜市》的游客会买烤鱿鱼，《雨天的街角书屋》的读者会借书。挪动桌椅能改变角色的下一步，两种结局分别记录。
- 可以输入自选主题，通过 Recraft 逐件生成，或者复制绘图单后导入其他 AI 绘制的透明四格 PNG。玩家可以检查分件预览、单独摆放贴纸，并从收藏重新打开主题盒。
- v0.4「灯火夜市」提供四张可单独摆放的透明贴纸。客人会走到附近的摊位买餐，有桌椅时落座，挪远凳子就改为外带。
- 可以直接玩内置夜市。接入绘图服务后，也可以按自己的主题分别生成摊位、桌、椅和客人，和其他夜市的贴纸混搭。
- 下载包还收录了两盒街景拼图、自由造景、街角手记和离线拼图礼物。
